# Discovery Web Piscine

## About

This repository contains my work for the Discovery Web Piscine.
The exercises helped me practice Linux commands, Git, GitHub, and basic development workflows.

## Git Workflow

The basic workflow I used is:

1. Edit the files
2. Add the changes with `git add`
3. Save the changes with `git commit`
4. Upload the changes with `git push`

## Why Git Makes Development Easier

Git makes development easier because it keeps track of changes made to the code. This means I can see previous versions and understand what was changed.

It also helps protect the project because changes are saved in the Git history. If something goes wrong, I can check the previous commits.

Git is also useful when working with a team because everyone can share their changes through a repository such as GitHub.

## SSH

I used an Ed25519 SSH key to connect my local Git repository to GitHub securely without entering my password every time.
